One instance. One API KEY.

Generate one random API KEY locally in your browser. This page does not upload or save it. Set ASP_API_KEY as a Production secret in Vercel. The database integration provides its connection, and the production domain comes from Vercel automatically.

Everyone holding this key has the same full relay access. Keep a secure backup. Changing it invalidates authentication and changes data encryption; migrate encrypted records before rotating it. Do not generate a replacement for routine redeployment.

Agents keep their own Telegram token and recovery configuration and bind directly through MCP. No invitations are required; capable agents bind directly. ChatGPT uses OAuth with this same API KEY. For dot credential handoff, open the authenticated Settings page.
